## 📖 Acerca del proyecto
Este paquete de texturas agrega texturas de mayor resolución al videojuego **[Dragon Ball Z - Budokai Tenkaichi 4](https://teambt4.wixsite.com/teambt4projects/descarga)**, diseñado para ejecutarse de manera fluida en el emulador de PlayStation 2 **[PCSX2](https://pcsx2.net/)**. ¡Disfruta de menús, personajes y entornos más nítidos en alta definición!

---

## 🚀 Características
- 🌟 Texturas de alta resolución para personajes, interfaz de usuario (UI) y escenarios.
- ⚙️ Optimizado para ser compatible con las funciones de reemplazo de texturas de PCSX2.
- 🔄 Actualizado regularmente para las versiones más recientes del mod BT4.

---

## 🛠️ Guía de Instalación

### PCSX2 (Emulador de PS2 para PC)
1. **Descarga** el archivo ZIP que contiene las texturas desde la [página oficial](https://angel06a.github.io/BT4-HD/).
2. **Descomprime** el archivo descargado.
3. Localiza tu carpeta **"Textures"** de PCSX2 (por defecto, se encuentra en la carpeta raíz o de datos del emulador).
4. **Coloca la carpeta** con el ID del juego (ej., `SLUS-XXXXX`) que contiene las texturas dentro del directorio `Textures`.
5. Asegúrate de que el reemplazo de texturas esté habilitado en la configuración gráfica de tu PCSX2.

📺 **Videotutorial:** [Mira la guía paso a paso en YouTube](https://www.youtube.com/watch?v=ZZWElA5SZM8)
