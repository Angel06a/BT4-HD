## 🛠️ Installation Guide

### PCSX2 (PS2 Emulator for PC)
1. **Download** the ZIP file containing the textures from the [official website](https://angel06a.github.io/BT4-HD/).
2. **Unzip** the downloaded file.
3. Locate your PCSX2 **"Textures"** folder (by default, it is located in the emulator's root or data folder).
4. **Place the folder** with the game ID (e.g., `SLUS-XXXXX`) containing the textures inside the `Textures` directory.
5. Make sure texture replacement is enabled in your PCSX2 graphics settings.

📺 **Video Tutorial:** [Watch the step-by-step guide on YouTube](https://www.youtube.com/watch?v=ZZWElA5SZM8)
